# notion · SRGH IT

`sarangmc.kr/note`에서 사용하는 IT팀 문서 공간입니다. 설치 프로젝트의 Spring Boot + React 배포 구조를 기반으로 하며, 문서 본문과 첨부파일의 복제 원본은 PostgreSQL 5432의 `srghnotion`에 저장합니다. 첨부파일은 1.77·1.78의 `/home/semin5/srgh/note/images/<문서 ID>/` 또는 `files/<문서 ID>/`에도 파일로 보관합니다. 두 서버는 DB 복제본을 이용해 누락된 로컬 파일을 동기화하므로 장애 전환 후에도 다운로드할 수 있습니다.

- 프런트엔드: React, Tiptap 편집기. 제목 즉시 반영과 자동 저장, 경로 표시, 하위 페이지, 검색, 텍스트 선택 시 서식 메뉴, 빈 블록의 `+` 메뉴 및 `/` 블록 검색, 표·체크리스트·코드 블록·이미지·파일 첨부, 본문 안 PDF 미리보기.
- 백엔드: 양쪽 서버의 `SRGH_IT-notion.service` / 3019, JDBC, DB 이벤트 폴링 기반 SSE. 로컬 첨부파일은 1분마다 DB 기준으로 동기화하며, 요청된 파일이 없을 때 즉시 복원합니다.
- 인증: `/it` 로그인 후 발급받은 1분짜리 감사 토큰을 백엔드에서 검증하고, `/notion` 범위의 15분 세션으로 교환합니다. 브라우저는 5분마다 `/it` 로그인을 재확인합니다.
- 데이터: `documents`, `attachments`, `change_events`. 노션 자체 로그인 세션은 없으며 각 API 요청에서 `/it` 로그인을 확인합니다. 파일당 최대 50MB입니다.
- 휴지통: 페이지 삭제 시 하위 페이지도 함께 숨깁니다. 휴지통에서 같은 묶음을 복원할 수 있고, 영구삭제 시 문서와 첨부파일을 제거합니다. 영구삭제는 되돌릴 수 없습니다.
- 동시 수정: 자동 저장은 버전 비교로 충돌을 감지하며, 실시간 동시 편집 커서/CRDT 병합은 제공하지 않습니다.

로컬 빌드: `frontend`에서 `npm ci`, `npm run build` 후 루트에서 `mvn test package`를 실행합니다. `deploy/schema.sql`은 신규 DB의 최초 생성에만 사용합니다.
